# Kellmarks 02.02.01

## Corrected downloadable Compose installation

Classification: **bug fix**, from 02.02.00 to 02.02.01. GitHub renamed the first
release's standalone `.env.docker.example` asset, making the minimal download
instructions inconsistent with the published filename. The full installation
archive and both GHCR architectures worked; no private data was affected.

The standalone template now ships as `env.docker.example`. Linux/macOS and
PowerShell examples save it as `.env.docker.example` locally. The source checkout
and tar bundle retain that original hidden name. SHA256SUMS uses the actual
public asset filename. A post-publication verification step downloads all assets
and compares names, sizes and SHA-256 hashes with the prepared inputs before
promoting `latest`. A mismatch stops promotion rather than declaring success.

Install with `docker-compose.yml` and `ghcr.io/paulkakell/kellmarks:02.02.01`.
Read the [GHCR guide](../GHCR_INSTALLATION.md) for complete instructions and the
[operations guide](../INSTALLATION.md) for HTTPS, backups, restoration and source
builds. Both Linux AMD64 and ARM64 retain the full dashboard, authenticated Flask
API, Gunicorn, non-root/read-only runtime and private persistent data volume.

## Validation and security

Tests cover safe flat filenames, archive path preservation, checksums,
Linux/PowerShell links, and missing/renamed/extra/modified downloaded artifacts.
The full Python, JavaScript, browser, lint/type, Bandit/CodeQL, secret-scanning,
live Python dependency audits, clean-build, configuration, logging, performance
and both Docker-architecture checks remain release prerequisites. Exact outcomes
and commit identifiers are recorded in the pull request after execution.

No Python dependency pins, authentication flows, authorization, request limits,
logging fields, configuration defaults, APIs or schema-2 data change. No database
migration, data rewrite or live-server change is required. Downloads use the
existing job-scoped GitHub token; it is not placed in artifacts. Python dependency
audits and SBOM generation are not a complete operating-system image scan.

## Rollback

The preceding `v02.02.00` at commit
`acf2a949ee2e497a8939e1275f8ee26320d8b909` and its image remain available. Back up
the private library and `.env`, keep the same Compose project and volume, set
`KELLMARKS_IMAGE=ghcr.io/paulkakell/kellmarks:02.02.00`, then recreate with:

```bash
docker compose -f docker-compose.yml up -d --no-build --force-recreate --wait
```

Recheck authenticated health and bookmarks. Never use `down -v` for an upgrade
or rollback. Schema 2 needs no reverse migration. For the older release's
standalone environment download, use `default.env.docker.example`; its archive
still contains `.env.docker.example`. Released tags and images are not overwritten.
